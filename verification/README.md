# Reproduce the finite checks

The analytical statements and their quantifiers are proved in [the memory law](../science/memory_law.md), [control structure](../science/control_structure.md) and [classical boundary](../science/classical_boundary.md). This directory checks concrete quantum channels and Hamiltonians where an incorrect reset, an uncounted carrier, a rank calculation or an order-of-limits mistake would change the conclusion. Passing these checks does not prove the general theorem or establish literature priority.

From the repository root, with Python 3.12 or a compatible newer version:

```bash
python3 -m pip install -r verification/requirements.txt
python3 verification/check_science.py --output verification/results.json
```

The program raises an exception on a failed check, prints one `PASS` line for each completed group and writes a report only after all groups pass. [results.json](results.json) records the actual run, package versions, fixed random seed, numerical tolerance, finite cases and observed values. The default output path is also `verification/results.json`. The exact Lie calculation uses rational symbolic arithmetic; the density matrices and propagators use double precision with tolerance $`2\times10^{-10}`$.

| Check | Actual calculation | What it tests |
| --- | --- | --- |
| Bell transmission across a reset | For payload dimensions 2, 3 and 4, construct a Bell pair and a pure or mixed correlated state of the bath factor and an invisible factor. Apply explicit SWAP matrices, the full Kraus trace-and-replace channel on the accessible payload, retrieval and a final bath trace. | The sealed reference survives, the entire accessible input carrier is physically erased, and the bath alone returns the Bell half. |
| Classicalizing the carrier | Apply the explicit projective dephasing channel to the bath carrier between writing and retrieval. Compute Bell acceptance and full half trace distance, including a product two-round Bell measurement. | Preserving basis labels does not preserve the reference correlations; one round has Bell acceptance $`1/r`$, and the tested two-round qubit example has acceptance $`1/4`$. This is one classical stand-in, not an optimization over all classical simulators. |
| Finite dimension obstruction | For every $`2\le r\le6`$ and $`1\le D\le r`$, decode an actual mixed state on $`R\otimes M_D`$ by a local isometry and evaluate its Bell overlap. Also construct saturating Schmidt-rank-$`D`$ states. | The finite Bell bound $`D/r`$ concerns coherent dimension and survives mixing and local decoding. The general statement follows from the written Schmidt-number proof. |
| Physical compression with a classical branch | Encode a Bell half into at most $`D`$ levels using a CPTP block-selection instrument, retain the block label classically, and decode each branch. Check completeness, trace preservation and the unchanged sealed-reference marginal. | The bound is attainable by this channel when $`D`$ divides $`r`$. For a smaller final block the program reports the actual lower overlap; it does not claim universal channel saturation in every dimension. |
| Qutrit-port Lie algebra | Starting only with the eight local qutrit generators and $`H_g=C\otimes Z+gI\otimes X`$, form commutators and perform exact rational real-coordinate elimination until closure or the full traceless dimension is reached. | The dimensions are exactly 16 at $`g=0`$ and 35 at the tested nonzero values $`g=1,1/3`$. No floating rank threshold is used. The statement for **every** nonzero $`g`$ comes from the analytical spanning argument. |
| Finite-time perturbation | Evolve the qutrit–qubit Hamiltonians by matrix exponentials, apply a two-outcome port instrument, choose a later control and idle duration from its outcome, and retain both classical output flags and a reference. | At 18 tested combinations of initial bath rank, coupling and hard horizon, the actual flagged half trace distance obeys $`d_T\le\min\{1,\lvert g\rvert T\}`$. The example is not a search over testers or a formula for the optimal finite-horizon memory. |
| Weighted sectors | Construct one bath state with actual inter-sector coherences, prescribed controllable dimensions $`(1,2,4)`$ and invisible dimensions $`(2,1,2)`$. Compare two controlled full-bath intervals with a reduced classical-sector realization after tracing invisible factors. | The projector probabilities recover $`(0.6,0.3,0.1)`$; the tested reference-complete output reduction agrees numerically. The corresponding memory staircase is $`(0.4,0.1,0.1,0)`$. A physical two-round dimension-2 compressor on the four-level sector has weighted Bell-event probability $`0.025`$, versus $`0.1`$ for ideal storage. |

The weighted-sector check starts from a **supplied** block structure. It does not infer that structure from an unknown Hamiltonian. The random block unitaries verify the reduced-model mechanism; they are not claimed to be pulses compiled from the qutrit example.

The storage checks use ideal effective SWAPs and exact resets. They do not verify the control-theoretic synthesis theorem, construct a pulse sequence, bound compilation time or simulate an infinite repeated test. The random finite cases supplement exact inequalities and symbolic closure; they neither exhaust all quantum channels nor replace the uniform repeated-tester proof. No test asserts a general noncommuting-control or finite-time approximation theorem from numerical agreement alone.
